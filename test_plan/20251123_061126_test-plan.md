# Application - Feature Test Plan
## Application Overview
This test plan outlines the steps to create a new account in Salesforce. The process involves navigating to the Accounts section, filling out the necessary fields, and saving the new account.

## Test Scenarios
### 1. Create New Account in Salesforce
**Seed:** tests/seed.spec.ts

#### 1.1 Steps to Create Account
**Steps:**
1. Navigate to the Salesforce home page.
2. Click on the "Accounts" link to access the Accounts section.
3. Click on the "New" button to initiate the account creation process.
4. Fill in the "Account Name" field with a valid name.
5. Fill in the "Phone" field with a valid phone number.
6. Fill in the "Website" field with a valid website URL.
7. Select an option from the "Type" dropdown.
8. Fill in the "Description" field with relevant information.
9. Select a "Parent Account" if applicable.
10. Click on the "Save" button to create the account.

**Expected Results:**
- Step 1: The Salesforce home page should load successfully.
- Step 2: The Accounts section should display a list of accounts.
- Step 3: The New Account form should open.
- Step 4: The "Account Name" field should accept input.
- Step 5: The "Phone" field should accept input.
- Step 6: The "Website" field should accept input.
- Step 7: The "Type" dropdown should allow selection.
- Step 8: The "Description" field should accept input.
- Step 9: The "Parent Account" dropdown should allow selection.
- Step 10: The new account should be created and displayed in the Accounts list.
