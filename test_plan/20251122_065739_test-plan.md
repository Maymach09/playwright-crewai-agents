# Application - Feature Test Plan
## Application Overview
This test plan covers the process of creating and deleting an account in Salesforce. The workflow includes navigating to the Accounts section, creating a new account with required fields, and subsequently deleting that account.

## Test Scenarios
### 1. Create and Delete Account in Salesforce
**Seed:** tests/seed.spec.ts

#### 1.1 Create Account
**Steps:**
1. Navigate to the Accounts section.
   - Element: Accounts link
   - Expected Result: Accounts page is displayed.
2. Click on the "New" button to create a new account.
   - Element: New button
   - Expected Result: New Account form is displayed.
3. Fill in the "Account Name" field with "Test Account".
   - Element: Account Name textbox
   - Expected Result: Account Name is set to "Test Account".
4. Fill in the "Phone" field with "123-456-7890".
   - Element: Phone textbox
   - Expected Result: Phone is set to "123-456-7890".
5. Click the "Save" button to create the account.
   - Element: Save button
   - Expected Result: Account "Test Account" is created successfully.

#### 1.2 Delete Account
**Steps:**
1. Click on the "Show more actions" button for the account.
   - Element: Show more actions button
   - Expected Result: More actions menu is displayed.
2. Click on the "Delete" option.
   - Element: Delete option
   - Expected Result: Confirmation dialog for deletion is displayed.
3. Confirm the deletion by clicking the "Delete" button in the dialog.
   - Element: Delete button
   - Expected Result: Account "Test Account" is deleted successfully.

**Expected Results:**
- Step 1: Accounts page is displayed.
- Step 2: New Account form is displayed.
- Step 3: Account Name is set to "Test Account".
- Step 4: Phone is set to "123-456-7890".
- Step 5: Account "Test Account" is created successfully.
- Step 1 (Delete): More actions menu is displayed.
- Step 2 (Delete): Confirmation dialog for deletion is displayed.
- Step 3 (Delete): Account "Test Account" is deleted successfully.
