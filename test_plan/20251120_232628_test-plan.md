# Application - Feature Test Plan
## Application Overview
Salesforce is a cloud-based application that provides customer relationship management (CRM) services. The application allows users to manage customer accounts, track sales, and automate marketing processes.

## Test Scenarios
### 1. Create New Account
**Seed:** tests/seed.spec.ts
#### 1.1 Create Account with Required Fields
**Steps:**
1. Navigate to the Accounts section by clicking on the 'Accounts' link in the navigation menu.
2. Click on the 'New' button to create a new account.
3. Fill in the 'Account Name' field with a valid name.
4. Fill in the 'Phone' field with a valid phone number.
5. Optionally fill in the 'Website', 'Type', and 'Description' fields.
6. Select the 'Parent Account' if applicable.
7. Click on the 'Save' button to save the new account.
8. Verify that the account is created successfully and appears in the Accounts list.

**Expected Results:**
- Step 1: The Accounts page should load successfully.
- Step 2: The New Account form should be displayed.
- Step 3: The 'Account Name' field should accept the input.
- Step 4: The 'Phone' field should accept the input.
- Step 5: The optional fields should accept the input.
- Step 6: The 'Parent Account' should be selectable.
- Step 7: The account should be saved without errors.
- Step 8: The new account should be visible in the Accounts list.
