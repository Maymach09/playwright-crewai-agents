# Application - Feature Test Plan
## Application Overview
This test plan outlines the steps to create a new account in Salesforce. The process involves navigating to the Accounts section, filling out the necessary information, and saving the new account.

## Test Scenarios
### 1. Create New Account in Salesforce
**Seed:** tests/seed.spec.ts
#### 1.1 Create Account
**Steps:**
1. Navigate to the Accounts section.
   - **Element:** Accounts Tab
   - **Action:** Click on the Accounts tab.
2. Click on the New button to create a new account.
   - **Element:** New Button
   - **Action:** Click on the button labeled "New".
3. Fill in the Account Name field.
   - **Element:** Account Name Input
   - **Action:** Type "Test Account" into the input field.
4. Fill in the Phone field.
   - **Element:** Phone Input
   - **Action:** Type "123-456-7890" into the input field.
5. Click on the Save button to save the new account.
   - **Element:** Save Button
   - **Action:** Click on the button labeled "Save".

**Expected Results:**
- Step 1: The user is navigated to the Accounts section.
- Step 2: A new account creation form is displayed.
- Step 3: The Account Name field is populated with "Test Account".
- Step 4: The Phone field is populated with "123-456-7890".
- Step 5: The new account is saved successfully, and the user is redirected to the Accounts list with the new account listed.
