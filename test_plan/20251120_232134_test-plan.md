# Application - Feature Test Plan
## Application Overview
This test plan outlines the steps to create a new account in Salesforce. The process involves navigating through the Salesforce interface, filling out the required fields, and submitting the form.

## Test Scenarios
### 1. Create New Account in Salesforce
**Seed:** tests/seed.spec.ts
#### 1.1 Create Account
**Steps:**
1. Navigate to Home → Accounts → New
2. Fill in the Account Name field: 
   - Action: Type "Test Account" into the textbox.
   - Locator: `getByRole('textbox', { name: 'Account Name' })`
3. Fill in the Phone field (optional):
   - Action: Type "123-456-7890" into the textbox.
   - Locator: `getByRole('textbox', { name: 'Phone' })`
4. Click the Save button:
   - Action: Click on the button to save the new account.
   - Locator: `getByRole('button', { name: 'Save' })`
5. Verify the account creation:
   - Expected Result: The URL should change to `/lightning/r/Account/[id]/view`, indicating the account was created successfully.

**Expected Results:**
- Step 1: User is navigated to the New Account form.
- Step 2: The Account Name field is populated with "Test Account".
- Step 3: The Phone field is populated with "123-456-7890".
- Step 4: The new account is saved successfully.
- Step 5: The user is redirected to the account view page.

### Edge Cases
- Attempt to save without filling in the Account Name field.
- Verify error messages for required fields.
- Check the behavior when entering invalid phone numbers.

This test plan is structured to ensure comprehensive coverage of the account creation process in Salesforce, allowing for both happy path and edge case testing.
